# Contributing

`viewport18-gate` is a maintenance-only personal research utility provided **AS-IS** with **No SLA** and **No Support Guarantees**.

## Policy on Pull Requests & Issues

- **Unsolicited AI-generated pull requests or bulk cosmetic/refactor PRs are closed without review.**
- Bug reports must use the reproducible bug report issue template and include a minimal standalone HTML/CSS reproducer.
- Feature requests and general support questions are out of scope.
- By submitting a Contribution, you agree that it is licensed under the Apache License, Version 2.0 (Section 5 of `LICENSE`) and contains only permissive dependencies compatible with Apache-2.0.
